# RJNX Gaming Esports - Complete Project Documentation

## 📋 Project Overview
A modern gaming esports tournament website with full-stack implementation.

## 🎮 Tech Stack
- **Frontend**: React.js + Vite
- **Backend**: Node.js + Express
- **Database**: MongoDB
- **Real-time**: Socket.io
- **Styling**: Tailwind CSS + Framer Motion
